# Frontend handoff — 2.1 Durable-work dead letters

Operator-only. It has no home until the operator control room (3.10, parked) exists, so do not build it before then.

Wanted: a list of `dead`/`failed` durable-work records (kind, resource, attempts, sanitized last error, timestamps), a re-enqueue action, and the queue-lag gauge. There is no RPC yet. Add `ListDeadWork(kind, limit)` and `ReenqueueWork(dedup_key, kind)` to `OpsService` over `durablework.ListDead` and `Enqueue`. Return the payload as opaque JSON, with one list filtered by kind and no per-kind endpoints.
