# Frontend handoff — 2.10 Incremental per-node allocation sync

Backend-only. No console UI is required for this change.

## What changed

Agent sync now uses checkpoint-plus-diff instead of resending the full node
configuration on every change and reconnect. The per-node allocation revision
(`desired_revision`) orders bounded start/update/stop diffs. Checkpoints
establish or repair the desired set on initialization, recovery, compaction,
cursor mismatch, or epoch change. Node config, pull credentials, and replica
discovery are independently versioned (content hashes) and sent only when
changed. Local-store format is now 3; wire checkpoints and diffs must not
carry registry credentials.

## API contracts

No platform API (`platformv1`) changes. Agent stream (`agentv1`) changes:

- `AgentHello` gains `accepted_node_config_version`,
  `accepted_credentials_version`, `accepted_replicas_version` (content hashes,
  empty when none). `reconciliation_cursor` remains the allocation revision.
- `DesiredNodeState` is now a checkpoint (allocations, volumes, node config).
  It gains `node_config_version` and loses `replica_addresses`. Services must
  have empty `registry_username`/`registry_password` on the wire.
- New `AllocationDiff` (`base_revision`/`target_revision`, `starts`,
  `updates`, `stops`, `volume_starts`, `volume_stops`), `NodeConfigUpdate`,
  `PullCredentialSet`, and `ReplicaEndpoints`, each fenced by
  `agent_id`/`cluster_id`/`session_id`/`authority_epoch`/`authority_not_after`.
- `DesiredStateAcknowledgement` carries the cumulative cursor plus all three
  stream versions.
- `AgentServerMessage` may carry any of the five payloads, in batch order:
  node config, credentials, allocations (checkpoint or diffs), replicas.

## Acceptance criteria

- Unchanged reconnect sends no allocation payload; matching healthy
  containers are not restarted.
- Missed stops arrive as explicit diff stops (omission alone never removes
  in diffs).
- Compacted or unavailable cursors fall back to a checkpoint.
- Failover resets history and recovers via checkpoint, then resumes diffs.
- Stale-epoch diffs are rejected; gaps require a checkpoint.
- Extra or unowned containers stay quarantined in recovery; owned-only
  inventory exits recovery.
- Credential rotation and replica changes do not manufacture allocation
  changes.

## Deferred UI

None. If the console ever surfaces per-node sync position, it should show
the allocation cursor plus the three content-hash versions from hello/ack,
but no such surface exists today.
