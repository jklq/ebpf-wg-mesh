# Frontend handoff — 1.8 Safe deletion

Deletes now tombstone for a grace period (default 7 days) and can be restored. The console has no UI for it yet.

## Build

1. **Delete dialogs** for project, production environment, and volume. Call `Preview{Project,Environment,Volume}Deletion` first and list what will go with it, then require the current name to be typed (`confirmation_name`). Other deletes need no confirmation.
2. **Recently deleted** view: list with `include_deleted`, show `deletion.delete_expires_at`, and call `Restore*`. Volumes have no restore, so show them as non-recoverable.

## Rules

- Keep the dialog open on `FailedPrecondition` (name mismatch, volume in use) and show the message.
- Restore goes top-down: restoring a child under a deleted parent fails, so say "restore the parent first".
- Default lists never show tombstoned resources. `deletion.inherited` means an ancestor was deleted.
