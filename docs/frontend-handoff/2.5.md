# Frontend handoff — 2.5 Build cancellation and attempts

## Build (users)

1. Show a **cancelling** state while a running build has `cancel_requested_at` set, until it reaches `cancelled`.
2. On build detail, show `attempt_count/attempt_limit` and an attempt history from `ListBuildAttempts` (builder, outcome, detail). This explains retries after worker loss.

## Later (operators)

The `OpsService` builder list and drain (`ListBuilders`, `SetBuilderDrain`) and the queue pause (`GetBuildScheduler`, `SetBuildSchedulerPaused`) wait for the operator control room (3.10, parked).
