# Frontend handoff — 2.9 Durable logs

`ListServiceLogs` is now paginated and reports dropped lines. The current viewer assumes one response holds the whole range, and that is no longer true.

## Build

1. Page lines with `page_token`/`next_page_token` and gaps with `gap_page_token`/`next_gap_page_token`. The two paginate independently and both move forward only.
2. Render each gap in the timeline as "N lines dropped (reason)" at its window, never as a silent hole.
3. When a line is `truncated`, show a "truncated at 64 KiB" note.
4. Render lines with a non-empty `event` (platform events such as `deploy.started`) distinctly from customer output, with their `attributes` available on expand.
5. In project settings, add a log retention control (1–90 days or platform default, `0`) that calls `UpdateProjectLogRetention`. Keep user input on `InvalidArgument`.
